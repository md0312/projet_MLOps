# Décisions du projet

Chaque fichier de ce dossier documente une décision importante, sous la forme d'un
*Architecture Decision Record* (ADR) : le **contexte**, la **décision** prise et ses
**conséquences**. L'objectif est de garder une trace des choix réalisés en équipe et de
leur justification.
